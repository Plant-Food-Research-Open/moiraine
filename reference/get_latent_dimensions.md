# Get latent dimensions levels from dimension reduction output

Extracts the latent dimension levels from the output of a dimension
reduction method.

## Usage

``` r
get_latent_dimensions(method_output)
```

## Arguments

- method_output:

  Integration method output generated via the
  [`get_output()`](https://plant-food-research-open.github.io/moiraine/reference/get_output.md)
  function.

## Value

A character vector giving the labels of the latent dimensions.
