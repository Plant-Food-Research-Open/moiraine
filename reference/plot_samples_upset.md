# Upset plot of samples

Generates an upset plot to compare the samples present in each omics
dataset.

## Usage

``` r
plot_samples_upset(mo_data)
```

## Arguments

- mo_data:

  A
  [MultiDataSet::MultiDataSet](https://rdrr.io/pkg/MultiDataSet/man/MultiDataSet-class.html)
  object.

## Value

An upset plot.
