# Number of features in each dataset of MultiDataSet object

Gives the number of features in each dataset of a MultiDataSet object.

## Usage

``` r
n_features(mo_data)
```

## Arguments

- mo_data:

  A
  [MultiDataSet::MultiDataSet](https://rdrr.io/pkg/MultiDataSet/man/MultiDataSet-class.html)
  object.

## Value

A named integer vector, where each element is the number of features in
the corresponding dataset.
